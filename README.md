# Store-sales-analysis
Анализ продаж магазина с выводами для практического применения

## Задачи
Выявить причины убытков и найти потенциальные точки роста.   
## Решение
Состоит из 3 частей-анализов: покупателей, товаров и скидок.   
### Анализ покупателей
Разделим покупателей с помощью RFM-сегментации и найдем таких, которые могут положительно отреагировать на скидку или акцию. При этом не предлагать скидку постоянным клиентам, чтобы избежать расходов.   
### Анализ товаров
Посмотрим какие категории товаров приносят больше выручки, а значит требуют большего внимания. Выявим какие товары возвращают больше всего, чтобы устранить причины возврата.
### Анализ скидок
Поскольку процент маржи неизвестен, сделаем оценку в диапазоне от 15% до 50%. Посчитаем какие товары выгодно продавались, если даже маржа была бы 15%, а какие - невыгодно, даже при 50%. Таким образом, можно скорректировать скидку. Например, если нужно продать товаров со скидкой в несколько раз больше, чем без скидки, то, возможно, стоит уменьшить размер скидки.
